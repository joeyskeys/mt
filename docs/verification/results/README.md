# Recorded verification results

Store completed Plan 18 records in this directory. Use a filename that
identifies the macOS/device/build, for example:

```text
2026-10-18-macos-device-release.json
```

Do not place an unverified claim here. A result is useful only when its
metadata identifies the exact `mt` commit, SDK, build configuration, device
registry ID, and command that produced it.
